1. Exact Brand Colors

Use these existing XASIL brand colors consistently:

* Deep Green: #06393E
* Dark Green: #042729
* Gold: #D39E43
* Cream: #F6F4EE
* Light Green: #EEF2EC
* White: #FFFFFF

Follow the screenshot’s visual balance:

* Header: white or cream background, dark green logo and icons.
* Main headings: deep green, bold and prominent.
* Primary buttons and selected tabs: deep green backgrounds with gold text or accents.
* Input fields and dropdowns: deep green backgrounds with white text and gold icons where appropriate.

2. Make All Icons Consistent

Review every icon throughout the entire application, including:

* Header and mobile navigation.
* Destination and location fields.
* Calendar and date selectors.
* Guests and capacity selectors.
* Search buttons.
* Hotel and apartment cards.
* Amenities and facilities.
* Airport Transfer and transport options.
* Wedding and event halls.
* Booking details and booking history.
* Login, account, and profile interfaces.
* Admin dashboard and property management.
* Forms, alerts, status indicators, and footer links.

Use one coherent icon family, preferably the existing icon library already installed in the project. If Lucide is already available, use consistent Lucide icons.

Icon rules:

* Use consistent stroke width, size, alignment, and visual weight.
* Use dark green or white for standard icons depending on the background.
* Use gold for selected states, important actions, and brand accents.
* Avoid mixing emoji, filled icons, outlined icons, and unrelated icon styles.
* Avoid oversized icons or unnecessary decorative symbols.
* Keep icons accessible and easy to recognize on mobile devices.
* Do not replace meaningful icons with text symbols or random Unicode characters.

Do not install another icon library if the existing one can meet the requirements.

* Deep green background.

Input fields and dropdowns

* Use the screenshot’s deep green style where appropriate.
